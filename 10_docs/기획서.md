# [기획서] MyFamily Hub - PWA 기반 개인 및 가족 통합 관리 시스템

## 1. 프로젝트 개요
* **프로젝트명:** MyFamily Hub (가칭)
* **목적:** 개인 자산, 구독 서비스, 주요 증명서/신분증 통합 관리 및 가족(2~3인) 간 데이터 안전 공유
* **배포 및 실행 방식:** iOS PWA (Progressive Web App)
  * Safari 접속 후 **[공유] ➔ [홈 화면에 추가]** 방식으로 네이티브 앱처럼 아이콘 생성 및 독립 실행
* **목표 운영 비용:** **0원/월** (오라클 클라우드 프리티어 + PWA 배포)
* **개발 환경:** Windows PC / macOS 모두 지원 (Cursor AI + Git + Docker/WSL2)

## 3. 기술 스택 및 시스템 구성

* **Frontend:** React / Next.js, Tailwind CSS, PWA Manifest (iOS Safari 최적화)
* **Backend:** Node.js (Express / NestJS) 또는 Python (FastAPI)
* **Database:** PostgreSQL (Docker 컨테이너로 인스턴스 내부 실행)
* **Infrastructure:** 오라클 클라우드 Always Free (Ubuntu ARM 4 OCPU / 24GB RAM)
* **AI Development Tool:** Cursor AI (Pro Plan 1개월)

## 4. 데이터베이스(DB) 구조 설계

```sql
-- 1. 가족 그룹
CREATE TABLE families (
  id SERIAL PRIMARY KEY,
  family_name VARCHAR(100) NOT NULL,
  invite_code VARCHAR(20) UNIQUE NOT NULL,
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- 2. 사용자 계정
CREATE TABLE users (
  id SERIAL PRIMARY KEY,
  email VARCHAR(255) UNIQUE NOT NULL,
  password_hash VARCHAR(255) NOT NULL,
  name VARCHAR(100) NOT NULL,
  family_id INT REFERENCES families(id),
  role VARCHAR(20) DEFAULT 'MEMBER',
  language_pref VARCHAR(10) DEFAULT 'ko'
);

-- 3. 자산 및 주식
CREATE TABLE assets (
  id SERIAL PRIMARY KEY,
  user_id INT REFERENCES users(id),
  family_id INT REFERENCES families(id),
  type VARCHAR(50) NOT NULL, -- cash, stock, account, etc.
  currency VARCHAR(10) NOT NULL, -- KRW, JPY, USD
  amount DECIMAL(15, 2) NOT NULL,
  stock_code VARCHAR(20),
  buy_price DECIMAL(15, 2),
  is_shared BOOLEAN DEFAULT false,
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- 4. 신분증 및 증명서
CREATE TABLE documents (
  id SERIAL PRIMARY KEY,
  user_id INT REFERENCES users(id),
  family_id INT REFERENCES families(id),
  doc_type VARCHAR(50) NOT NULL,
  doc_number VARCHAR(100),
  expiry_date DATE,
  image_url TEXT,
  is_shared BOOLEAN DEFAULT false
);

-- 5. 구독 서비스
CREATE TABLE subscriptions (
  id SERIAL PRIMARY KEY,
  user_id INT REFERENCES users(id),
  family_id INT REFERENCES families(id),
  service_name VARCHAR(100) NOT NULL,
  cost DECIMAL(10, 2) NOT NULL,
  currency VARCHAR(10) NOT NULL,
  billing_date INT NOT NULL, -- 결제일 (1~31)
  cancel_url TEXT,
  reason TEXT,
  is_shared BOOLEAN DEFAULT false
);

-- 6. 수입 및 지출 내역
CREATE TABLE transactions (
  id SERIAL PRIMARY KEY,
  user_id INT REFERENCES users(id),
  family_id INT REFERENCES families(id),
  category VARCHAR(50) NOT NULL,
  amount DECIMAL(15, 2) NOT NULL,
  currency VARCHAR(10) NOT NULL,
  date DATE NOT NULL,
  description TEXT,
  is_shared BOOLEAN DEFAULT false
);
```

## 5. 구축 및 실행 로드맵

1. **1단계: 오라클 클라우드 서버 세팅**
   * Ubuntu ARM 인스턴스 생성 ➔ Docker, PostgreSQL, Nginx (SSL/HTTPS) 환경 구축
2. **2단계: AI 기반 코드 개발 (Cursor AI)**
   * Cursor AI(Composer)를 활용하여 PWA 프론트엔드, 백엔드 API, Face ID(WebAuthn), OCR 기능 구현
3. **3단계: 서버 배포 및 PWA 세팅**
   * Docker Compose로 서버 실행 및 HTTPS 도메인 연결, Web Push 환경 세팅
4. **4단계: 가족 기기 설치 및 사용**
   * 각 아이폰 Safari 접속 ➔ **[공유] ➔ [홈 화면에 추가]** 진행 ➔ Face ID 등록 및 가족 초댓코드 연동
