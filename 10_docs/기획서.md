# [기획서] MyFamily Hub - PWA 기반 개인 및 가족 통합 관리 시스템

## 1. 프로젝트 개요
* **프로젝트명:** MyFamily Hub (가칭)
* **목적:** 개인 자산, 구독 서비스, 주요 증명서/신분증, 사진, 캘린더 통합 관리 및 가족(2~3인) 간 데이터 안전 공유
* **배포 및 실행 방식:** iOS PWA (Progressive Web App)
  * Safari 접속 후 **[공유] ➔ [홈 화면에 추가]** 방식으로 네이티브 앱처럼 아이콘 생성 및 독립 실행
* **목표 운영 비용:** **0원/월** (오라클 클라우드 프리티어 + PWA 배포)
* **개발 환경:** Windows PC / macOS 모두 지원 (Cursor AI + Git + Docker/WSL2)

## 3. 기술 스택 및 시스템 구성

* **Frontend:** React / Next.js, Tailwind CSS, FullCalendar / React-Big-Calendar, PWA Manifest (iOS Safari 최적화)
* **Backend:** Node.js (Express / NestJS) 또는 Python (FastAPI)
* **알림 스케줄링:** `node-cron` / APScheduler 등으로 캘린더 알림·만료 알림·구독 D-Day 알림을 주기적으로 검사 후 Web Push 발송
* **Database:** PostgreSQL (Docker 컨테이너로 인스턴스 내부 실행)
* **Infrastructure:** 오라클 클라우드 Always Free (Ubuntu 22.04 ARM, ap-osaka-1 리전) — 2 OCPU / 12GB RAM *(2026년 기준 Always Free ARM 한도가 4 OCPU/24GB에서 축소되어 실제 배포 스펙에 맞게 반영)*
* **AI Development Tool:** Cursor AI (Pro Plan 1개월)

## 4. 데이터베이스(DB) 구조 설계

```sql
-- 1. 가족 그룹
CREATE TABLE families (
  id SERIAL PRIMARY KEY,
  family_name VARCHAR(100) NOT NULL,
  invite_code VARCHAR(20) UNIQUE NOT NULL,
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- 2. 사용자 계정
CREATE TABLE users (
  id SERIAL PRIMARY KEY,
  email VARCHAR(255) UNIQUE NOT NULL,
  password_hash VARCHAR(255) NOT NULL,
  name VARCHAR(100) NOT NULL,
  family_id INT REFERENCES families(id),
  role VARCHAR(20) DEFAULT 'MEMBER',
  language_pref VARCHAR(10) DEFAULT 'ko',
  country_pref VARCHAR(10) DEFAULT 'JP',
  currency_pref VARCHAR(10) DEFAULT 'JPY' -- 메인 대시보드에서 설정, 앱 전체(자산/구독 등) 표시 통화에 동일 적용
);

-- 3. 자산 및 주식
CREATE TABLE assets (
  id SERIAL PRIMARY KEY,
  user_id INT REFERENCES users(id),
  family_id INT REFERENCES families(id),
  type VARCHAR(50) NOT NULL,
  currency VARCHAR(10) NOT NULL,
  amount DECIMAL(15, 2) NOT NULL,
  stock_code VARCHAR(20),
  buy_price DECIMAL(15, 2),
  is_shared BOOLEAN DEFAULT false,
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- 4. 신분증 및 증명서
CREATE TABLE documents (
  id SERIAL PRIMARY KEY,
  user_id INT REFERENCES users(id),
  family_id INT REFERENCES families(id),
  doc_type VARCHAR(50) NOT NULL,
  doc_number VARCHAR(100),
  expiry_date DATE,
  image_url TEXT,
  is_shared BOOLEAN DEFAULT false
);

-- 5. 구독 서비스
CREATE TABLE subscriptions (
  id SERIAL PRIMARY KEY,
  user_id INT REFERENCES users(id),
  family_id INT REFERENCES families(id),
  service_name VARCHAR(100) NOT NULL,
  cost DECIMAL(10, 2) NOT NULL,
  currency VARCHAR(10) NOT NULL,
  billing_date INT NOT NULL,
  cancel_url TEXT,
  reason TEXT,
  is_shared BOOLEAN DEFAULT false
);

-- 6. 수입 및 지출 내역
CREATE TABLE transactions (
  id SERIAL PRIMARY KEY,
  user_id INT REFERENCES users(id),
  family_id INT REFERENCES families(id),
  category VARCHAR(50) NOT NULL,
  amount DECIMAL(15, 2) NOT NULL,
  currency VARCHAR(10) NOT NULL,
  date DATE NOT NULL,
  description TEXT,
  is_shared BOOLEAN DEFAULT false
);

-- 7. 사진 및 앨범
CREATE TABLE photos (
  id SERIAL PRIMARY KEY,
  user_id INT REFERENCES users(id),
  family_id INT REFERENCES families(id),
  photo_url TEXT NOT NULL,
  icloud_asset_id VARCHAR(255),
  caption TEXT,
  is_shared BOOLEAN DEFAULT false,
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- 8. 캘린더 일정
CREATE TABLE calendar_events (
  id SERIAL PRIMARY KEY,
  user_id INT REFERENCES users(id),
  family_id INT REFERENCES families(id),
  title VARCHAR(200) NOT NULL,
  description TEXT,
  start_time TIMESTAMP NOT NULL,
  end_time TIMESTAMP NOT NULL,
  is_all_day BOOLEAN DEFAULT false,
  category VARCHAR(50) DEFAULT 'personal', -- 'personal' | 'family' | 'holiday' | 'document_expiry'
  source_document_id INT REFERENCES documents(id), -- 증명서 만료일 자동 등록 시 연결
  reminder_minutes_before INT, -- 알림 시점 (예: 10, 60, 1440 = 1일 전), NULL이면 알림 없음
  is_reminder_sent BOOLEAN DEFAULT false, -- Web Push 발송 여부 (중복 발송 방지)
  is_shared BOOLEAN DEFAULT false,
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
