## 4. 현재 실행 방법

```bash
npm install
MEMORY_AUTH=1 npm run dev   # 또는 npm run dev (dev:server 가 MEMORY_AUTH=1)
# 웹: http://localhost:5173  → 먼저 /login 에서 가입
```

실 Postgres:

```bash
cd 40_server
docker compose -f docker-compose.dev.yml up -d
cp .env.example .env   # MEMORY_AUTH 없이 실행
npm run db:migrate
npm run dev            # workspace server, MEMORY_AUTH 끄고
```

공개 HTTP 목업(정적, API 없음): `http://sumicchogurashi.duckdns.org`  
개발 미리보기(설정 후): `http://sumicchogurashi-dev.duckdns.org` — 절차는 `10_docs/prod_dev_이중배포.md`
