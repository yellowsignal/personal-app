## 사전 준비 (민호님 PC / OCI 콘솔)

### A. OCI 인스턴스
- ✅ Public IP: `129.225.196.226`
- VCN Security List / NSG에 **Ingress TCP 80, 443**(및 SSH 22) 허용 유지

### B. DuckDNS 임시 도메인
- ✅ 계정 생성됨
- ✅ 도메인: `sumicchogurashi.duckdns.org` → `129.225.196.226`
- token은 로컬 메모에만 보관 (레포/채팅 커밋 금지)
- HTTP 확인: `http://sumicchogurashi.duckdns.org` → MyFamily Hub 목업 200

### C. HTTPS (기존 nginx 유지)

목업은 **이미 호스트 nginx(1.18)** 로 서빙 중입니다.  
`docker compose`의 nginx를 80/443에 또 올리면 충돌하므로, 지금은 **기존 nginx + certbot** 으로 HTTPS만 붙이는 편이 안전합니다.

1. ~~DuckDNS IP를 `129.225.196.226`으로 맞춤~~ ✅
2. 서버에서 certbot(nginx 플러그인 또는 webroot)으로 `sumicchogurashi.duckdns.org` 인증서 발급
3. HTTPS로 목업 접속 확인: `https://sumicchogurashi.duckdns.org`

(레포의 `40_server/infra/scripts/*` 는 Docker 기반 신규 구축용입니다. 기존 nginx를 유지할 때는 DuckDNS 갱신 + certbot만 진행하세요.)

## 나중에 도메인/이름 바꿀 때

1. 새 도메인(또는 새 DuckDNS) 발급
2. DNS A레코드를 `129.225.196.226`으로 지정
3. certbot으로 새 도메인 인증서 발급 / nginx `server_name` 갱신
4. (선택) 예전 도메인 → 새 도메인 리다이렉트

앱 UI 브랜드명(MyFamily Hub)과 도메인은 서로 달라도 됩니다.
