# 인프라 1단계 — OCI + 임시 도메인(DuckDNS) + Nginx/HTTPS

임시 도메인으로 서버를 먼저 올리고, 확정 도메인/브랜드명은 나중에 교체합니다.

현재 Cloud Agent 환경에는 OCI CLI / Docker / `90_secret`이 없어 **인스턴스 생성·SSH 배포는 PC(Windows 스크립트) 또는 인스턴스 안에서** 진행합니다.  
레포의 `40_server/infra/`는 인스턴스에 올린 뒤 바로 실행할 수 있게 준비해 두었습니다.

## 목표

1. Oracle Cloud Always Free ARM 인스턴스 RUNNING + public IP
2. DuckDNS 임시 도메인 A레코드 → public IP
3. Docker Compose로 Postgres + Nginx (+ Certbot) 기동
4. Let's Encrypt HTTPS 발급
5. `https://<임시도메인>` 접속 시 “server is up” 문구 확인

## 사전 준비 (민호님 PC / OCI 콘솔)

### A. OCI 인스턴스
- Windows에서 기존 재시도 스크립트 사용:
  - `40_server/infra/scripts/register-tasks.ps1`
  - 또는 `retry-launch-instance.ps1`
- 성공 시 Compute → Instances에서 **RUNNING** / **Public IP** 확인
- VCN Security List / NSG에 **Ingress TCP 80, 443** 허용

### B. DuckDNS 임시 도메인
1. https://www.duckdns.org 로그인
2. 서브도메인 생성 (예: `myfamilyhub` → `myfamilyhub.duckdns.org`)
3. token 복사 (레포에 커밋하지 말 것)

### C. 서버에 코드 올리기
SSH로 인스턴스 접속 후 저장소를 clone 하거나, 최소 `40_server/infra/`만 복사합니다.

```bash
cd ~/personal-app/40_server/infra   # 경로 예시
cp .env.example .env
nano .env   # DOMAIN, LETSENCRYPT_EMAIL, DUCKDNS_*, POSTGRES_PASSWORD 수정
```

## 인스턴스에서 실행 순서

```bash
cd ~/personal-app/40_server/infra/scripts
chmod +x *.sh

# 1) Docker 설치 + HTTP 모드로 compose 기동
./bootstrap-ubuntu.sh

# 2) DuckDNS에 public IP 등록 (인스턴스 public IP를 넣거나 생략해 자동 감지)
./update-duckdns.sh <PUBLIC_IP>

# 3) DNS 전파 확인 후 인증서 발급 + HTTPS 전환
dig +short myfamilyhub.duckdns.org
./issue-cert.sh

# 4) 확인
curl -I http://myfamilyhub.duckdns.org
curl -I https://myfamilyhub.duckdns.org
```

## 스크립트 요약

| 스크립트 | 역할 |
| --- | --- |
| `bootstrap-ubuntu.sh` | Docker 설치, HTTP nginx 렌더, compose up |
| `render-nginx.sh` | `.env`의 DOMAIN으로 nginx conf 생성 (`http`/`https`) |
| `update-duckdns.sh` | DuckDNS A레코드 갱신 |
| `issue-cert.sh` | Let's Encrypt 발급 후 HTTPS conf로 전환 |
| `retry-launch-instance.ps1` 등 | (Windows) Always Free 용량 날 때까지 인스턴스 생성 재시도 |

## 나중에 도메인/이름 바꿀 때

1. 새 도메인(또는 새 DuckDNS) 발급
2. `.env`의 `DOMAIN` / `DUCKDNS_*` 수정
3. `./update-duckdns.sh` (또는 새 DNS A레코드)
4. `./issue-cert.sh` 재실행
5. (선택) 예전 도메인 → 새 도메인 리다이렉트

앱 UI 브랜드명(MyFamily Hub)과 도메인은 서로 달라도 됩니다.
