# 개인 계정 보관함 (Vault)

회사 사번, 사이트 아이디/비밀번호, MS Office 제품키 등 **본인만** 쓰는 민감 정보를 보관한다. 가족 공유 없음.

## UX

1. 홈 → **계정 보관함**
2. 추가: 이름, 종류(로그인 / 제품키 / 기타), 사이트, 아이디·사번, 비밀번호·키, 메모
3. 목록: 이름·종류·사이트만 표시 (민감값 없음)
4. 상세 → **Face ID로 보기** → 아이디·비밀번호(또는 제품키) 평문 + 복사

## 저장

| 필드 | 저장 | API 목록 노출 |
| --- | --- | --- |
| title, category, url, memo | 평문 | 예 |
| loginId | 평문(DB) | `hasLoginId`만. 평문은 reveal 후 |
| secretCipher | AES-256-GCM | `hasSecret`만 |

## API

| Method | Path |
| --- | --- |
| GET/POST | `/api/vault` |
| PATCH/DELETE | `/api/vault/:id` |
| POST | `/api/vault/:id/credentials/reveal/options` |
| POST | `/api/vault/:id/credentials/reveal/verify` → `{ loginId, secret }` |
