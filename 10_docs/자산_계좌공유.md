# 예금 계좌번호·비밀번호 가족 공유

아이 통장 등 **가족이 함께 알아야 하는 예금 계좌**의 계좌번호·비밀번호를 자산(예금)에 보관하고, 비밀번호는 **Passkey(Face ID) step-up** 후에만 평문으로 보여 준다.

일본 은행은 **金融機関コード / 銀行名 / 支店コード / 支店名** 도 같이 저장할 수 있다.

## UX

1. 예금 추가/수정(소유자): `계좌번호`, `비밀번호` 선택 입력 + 「가족과 공유」
2. 일본 은행(MUFG / ゆうちょ) 선택 시: 은행코드·은행명(프리필)·지점코드·지점명 입력
3. 목록: 정보가 있으면 「계좌 정보 저장됨」 표시 (비밀번호 평문 없음)
4. 상세(길게 누르기): 계좌번호·은행/지점 정보는 바로 표시, 비밀번호는 「보기」→ Face ID 후 평문
5. 명세 화면 **자동 입금**: 매월 또는 매년 일정 금액을 잔액에 반영 (아이 통장 적립)

## 접근 권한

| 동작 | 조건 |
| --- | --- |
| 계좌번호/비밀번호·은행 정보 저장·변경 | 자산 소유자만 |
| 목록에서 계좌번호·`hasPassword` 보기 | 자산을 볼 수 있는 사람(본인 또는 `is_shared` 가족) |
| 비밀번호 평문 reveal | 위 + **본인 Passkey 인증** 성공 |

공유하지 않은 개인 예금의 비밀번호는 소유자만 reveal 가능.

## 저장

- `account_number` — 평문(목록·상세에 노출)
- `login_password_cipher` — AES-256-GCM (구독과 동일 키)
- `institution_code` / `institution_name` / `branch_code` / `branch_name` — JP 이체 정보(평문)
- 키: `CREDENTIALS_ENCRYPTION_KEY`(64 hex) 또는 없으면 `sha256("credentials:"+JWT_SECRET)`

리스트/CRUD 응답에는 암호문·평문 비밀번호를 넣지 않는다. `hasPassword: boolean`만.

## API

| Method | Path | 설명 |
| --- | --- | --- |
| POST/PATCH | `/api/assets` | deposit body에 `accountNumber?`, `loginPassword?`, `institutionCode?`, `institutionName?`, `branchCode?`, `branchName?` |
| POST | `/api/assets/:id/credentials/reveal/options` | Bearer + Passkey options |
| POST | `/api/assets/:id/credentials/reveal/verify` | Bearer + assertion → `{ accountNumber, password }` |
| POST | `/api/assets/:id/recurring-deposits` | `billingInterval`: `MONTHLY` \| `YEARLY` |

Passkey가 없는 계정은 `PASSKEY_REQUIRED`(400).
