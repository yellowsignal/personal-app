# 구독 계정(ID/비밀번호) 가족 공유

Netflix 등 **가족이 같은 계정으로 쓰는 구독**의 로그인 ID·비밀번호를 앱에 보관하고, 비밀번호는 **Passkey(Face ID) step-up** 후에만 평문으로 보여 준다.

## UX

1. 구독 추가/수정(소유자): `로그인 ID`, `비밀번호` 선택 입력 + 기존처럼 「가족과 공유」
2. 목록 카드: ID가 있으면 표시, 비밀번호는 `••••••••` + 「보기」
3. 「보기」→ Face ID → 한 번만 평문 표시(클립보드 복사 가능). 세션 JWT만으로는 비밀번호 미포함

## 접근 권한

| 동작 | 조건 |
| --- | --- |
| ID/비밀번호 저장·변경·삭제 | 구독 소유자만 |
| 목록에서 ID·`hasPassword` 보기 | 구독을 볼 수 있는 사람(본인 또는 `is_shared` 가족) |
| 비밀번호 평문 reveal | 위 + **본인 Passkey 인증** 성공 |

공유하지 않은 개인 구독의 비밀번호는 소유자만 reveal 가능.

## 저장

- `login_id` — 평문(목록에 노출)
- `login_password_cipher` — AES-256-GCM (iv + tag + ciphertext, base64)
- 키: `CREDENTIALS_ENCRYPTION_KEY`(64 hex) 또는 없으면 `sha256("credentials:"+JWT_SECRET)`

리스트/CRUD 응답에는 암호문·평문 비밀번호를 넣지 않는다. `hasPassword: boolean`만.

## API

| Method | Path | 설명 |
| --- | --- | --- |
| POST/PATCH | `/api/subscriptions` | body에 `loginId?`, `loginPassword?` (빈 문자열이면 비밀번호 삭제, PATCH에서 생략이면 유지) |
| POST | `/api/subscriptions/:id/credentials/reveal/options` | Bearer + Passkey options (`allowCredentials`) |
| POST | `/api/subscriptions/:id/credentials/reveal/verify` | Bearer + assertion → `{ loginId, password }` |

Passkey가 없는 계정은 `PASSKEY_REQUIRED`(400).

## 보안 메모

- HTTPS 필수(이미 Passkey와 동일)
- reveal는 일회성 challenge(5분), 새 JWT를 발급하지 않음
- 감사 로그·자동 잠금은 이후 과제
