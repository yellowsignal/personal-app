# 역할 및 목표
당신은 React/Next.js, PWA(Progressive Web App), Node.js(Express/NestJS) 또는 Python(FastAPI), 그리고 PostgreSQL에 정통한 풀스택 개발 전문가입니다.
아이폰 Safari 환경([홈 화면에 추가])에 최적화된 개인 및 가족 통합 자산/개인정보 관리 PWA 애플리케이션("MyFamily Hub")을 개발해 주세요.

- **목표 운영 비용:** 0원/월 (오라클 클라우드 Always Free + PWA 배포)
- **개발 환경:** Windows PC / macOS 모두 지원 (Cursor AI + Git + Docker/WSL2)

## 1. 핵심 요구사항 및 시스템 아키텍처

### A. 사용자 인증 및 가족 공유 권한 모델
- **독립 로그인:** 가족 구성원은 각자 자신만의 계정(이메일/비밀번호 또는 생체인증)으로 로그인합니다.
- **가족 그룹 연동:**
  - 사용자가 가족 그룹을 생성하면 고유한 가족 초댓코드(예: `FAM-8X39A`)가 생성됩니다.
  - 다른 가족 멤버는 가입 시 이 초댓코드를 입력하여 해당 가족 그룹(2~3인)에 합류합니다.
- **데이터 개인/공유 권한 제어 (핵심):**
  - 모든 레코드(자산, 증명서, 구독, 수입/지출)에는 `is_shared` (Boolean) 토글 필드가 포함되어야 합니다.
  - `is_shared = false`: 작성자 본인만 조회 및 수정 가능 (개인 비공개)
  - `is_shared = true`: 동일한 `family_id`에 속한 모든 가족 멤버가 조회 가능 (가족 공유)
- **생체 인증:** iOS Face ID / Touch ID 로그인을 위해 WebAuthn API (Passkeys)를 연동합니다.

### B. 다국어 지원 (i18n)
- 한국어(ko)와 일본어(ja)를 모두 지원합니다.
- 설정 메뉴에서 언어를 즉시 변경할 수 있는 UI 스위처를 구현하고 `i18next`를 활용합니다.

### C. 주요 기능 모듈
1. **자산 관리 (Asset Management)**
   - 다중 통화 지원: 원화(KRW), 엔화(JPY), 달러(USD) 지원 및 실시간 환율 API 연동.
   - 대시보드에서 총자산을 KRW, JPY, USD로 자동 환산하여 실시간 표시.
   - 주식 포트폴리오: 보유 주식의 매수가, 현재가, 변동률 확인 (Yahoo Finance 등 무료 API 활용).
   - 수입/지출 내역 기록 및 카드/은행 명세서 파일(CSV, 이미지 OCR) 업로드 기능.

2. **증명서 및 신분증 (Documents & Credentials)**
   - 운전면허증, 자격증, 신분증, 여권 정보(번호, 유효기간) 등록 및 관리.
   - OCR 기능: 브라우저 카메라 또는 이미지 업로드를 통해 실물 카드의 번호와 유효기간 자동 추출.
   - 만료 알림 및 캘린더: Web Push 알림 제공 및 만료일을 앱 내 **캘린더 기능**(`calendar_events`)에 자동으로 일정 등록.

3. **구독 관리 (Subscription Management)**
   - 서비스명, 결제 금액, 통화, 결제 주기/D-Day, 사용 이유 관리.
   - 구독 해지 직링크(`cancel_url`) 버튼 제공.

4. **아이폰 PWA 최적화**
   - iOS Safari Standalone 모드를 위한 `manifest.json`, 테마 색상, 터치 아이콘, 웹 푸시 설정.

5. 사진 관리 및 공유 (iCloud 연동)
   - **개인 및 가족 앨범:** 사진 업로드 시 개인 보관(`is_shared = false`) 또는 가족 공유(`is_shared = true`)를 선택할 수 있습니다.
   - **iCloud 연동:** CloudKit API 또는 iCloud 공유 앨범 링크/WebDAV를 연동하여 사진을 동기화하고 관리할 수 있는 모듈을 구축해 주세요.

6. 캘린더 기능 (개인/가족 레이어 통합 View)
   - **개인 캘린더 vs 가족 캘린더:**
     - 본인의 개인 일정과 가족 전체 공유 일정을 별도 카테고리로 생성 및 관리합니다.
     - 캘린더 화면에서 "개인 일정", "가족 일정", "반복 일정" 체크박스를 제공하여 원하는 일정만 켜고 끄거나, 두 일정을 **한 눈에 겹쳐서(Overlay)** 볼 수 있도록 UI를 구성해 주세요.
     - 캘린더 UI 구현에는 `FullCalendar` 또는 `React-Big-Calendar` 라이브러리 활용을 권장합니다.
   - **국가별 공휴일 연동 (한국 / 일본):**
     - 사용자 프로필 설정(`country_pref`)에 따라 한국(KR) 또는 일본(JP)의 공휴일 데이터를 외부 API(예: Holidays API, Google Calendar iCal)에서 받아와 캘린더에 자동으로 표시해 주세요.
   - **증명서/신분증 만료일 연동 (`document_expiry` 카테고리):**
     - `documents` 테이블에 유효기간(`expiry_date`)이 등록/수정되면, 해당 만료일을 `calendar_events`에 `category = 'document_expiry'`, `source_document_id`로 연결된 일정으로 자동 생성(Upsert)해 주세요.
     - 캘린더 화면의 필터 토글에 "만료 알림" 항목을 추가하여 개인/가족 일정과 함께 켜고 끌 수 있도록 구성해 주세요.
   - **일정 알림 기능 (Web Push):**
     - 일정 생성/수정 화면에서 알림 시점을 선택할 수 있는 옵션을 제공해 주세요 (예: 없음, 10분 전, 1시간 전, 1일 전 → `reminder_minutes_before` 값으로 저장).
     - 백엔드에 스케줄러(`node-cron` 또는 APScheduler 등)를 두어 주기적으로(예: 1분마다) `start_time - reminder_minutes_before`가 현재 시각에 도달했고 `is_reminder_sent = false`인 일정을 조회하여 Web Push 알림을 발송하고, 발송 후 `is_reminder_sent = true`로 갱신해 주세요.
     - 가족 공유 일정(`is_shared = true`)의 경우 가족 멤버 전원에게 알림이 발송되도록 구성해 주세요.

### D. 운영 및 인프라
- **인프라:** 오라클 클라우드 Always Free (Ubuntu ARM 4 OCPU / 24GB RAM) 위에서 동작하도록 구성해 주세요.
- **Database:** PostgreSQL은 Docker 컨테이너로 인스턴스 내부에서 실행합니다.
- **AI 개발 도구:** Cursor AI (Pro Plan)를 기준으로 개발 워크플로우를 구성해 주세요.

## 2. 데이터베이스(DB) 구조 설계 (PostgreSQL)

아래 DDL 구조를 바탕으로 Prisma 또는 TypeORM 스키마/엔티티를 작성해 주세요:

1. `families` (id, family_name, invite_code, created_at)
2. `users` (id, email, password_hash, name, family_id [FK], role, language_pref, country_pref)
3. `assets` (id, user_id [FK], family_id [FK], type, currency, amount, stock_code, buy_price, is_shared, updated_at)
4. `documents` (id, user_id [FK], family_id [FK], doc_type, doc_number, expiry_date, image_url, is_shared)
5. `subscriptions` (id, user_id [FK], family_id [FK], service_name, cost, currency, billing_date, cancel_url, reason, is_shared)
6. `transactions` (id, user_id [FK], family_id [FK], category, amount, currency, date, description, is_shared)
7. `photos` (id, user_id [FK], family_id [FK], photo_url, icloud_asset_id, caption, is_shared, created_at)
8. `calendar_events` (id, user_id [FK], family_id [FK], title, description, start_time, end_time, is_all_day, category ['personal'|'family'|'holiday'|'document_expiry'], source_document_id [FK → documents], reminder_minutes_before, is_reminder_sent, is_shared, created_at)

## 3. 우선 작성해야 할 작업 순서

1. 전체 프로젝트 폴더 구조 및 기술 스택(Next.js + Tailwind + PostgreSQL/Prisma 등) 구성 안내.
2. PostgreSQL DB 스키마 파일(Prisma Schema 또는 DDL) 생성.
3. iOS Safari PWA 매니페스트 및 기본 레이아웃 구성.
4. 초댓코드 기반 가입/로그인 및 WebAuthn(Face ID) 인증 흐름 구현.
5. "내 비공개 데이터 보기"와 "가족 공유 데이터 보기" 탭 전환이 가능한 대시보드 UI 구현.

위 순서에 따라 폴더 구조와 스키마 파일부터 차례대로 작성해 주세요.
